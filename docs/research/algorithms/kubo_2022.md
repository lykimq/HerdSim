## Paper reference

- M. Kubo, M. Tashiro, H. Sato, et al.
- "Herd guidance by multiple sheepdog agents with repulsive force"
- Artificial Life and Robotics, 27, 416-427, 2022
- DOI: https://doi.org/10.1007/s10015-021-00726-7
- PDF: [../../papers/kubo_22.pdf](../../papers/kubo_22.pdf)

## Problem the paper solves

Multiple sheepdogs guide a flock to a goal using continuous repulsive and attractive forces. Dogs spread behind the flock via dog-dog repulsion and target sheep farthest from the goal within sensing range.

## Algorithm (written out)

### Sheep (each tick, before dogs)

Neighbours and dogs within radius `R`:

1. `a_i`: mean neighbour repulsion `diff / ||diff||^2`
2. `b_i`: mean unit velocity of moving neighbours (alignment)
3. `c_i`: cohesion `-mean(diff / ||diff||)`
4. `d_i`: mean dog repulsion `diff / ||diff||^3`
5. `v = K_s1 a + K_s2 b + K_s3 c + K_s4 d`, clamp to `sheep_speed_max`
6. `p <- p + dt * v`

### Dogs (after sheep positions update -- MATLAB order)

1. Find sheep within radius `R`.
2. If none: weak pull toward goal; zero other forces.
3. Else target = in-range sheep farthest from goal.
4. `A` unit attraction to target; `B` inverse-cube repulsion from target; `C` unit repulsion from goal; `D` mean inverse-cube repulsion from other dogs.
5. `v = K_f1 A + K_f2 B + K_f3 C + K_f4 D`, clamp, `p <- p + dt * v`

No discrete Collect/Drive modes.

## Agents

Default N=40 sheep, M=4 dogs.

## Paper parameters (accounts)

| Key | Default | Meaning / purpose / effect |
|-----|---------|----------------------------|
| `radius` (R) | 60 | Interaction radius. Larger -> more neighbours/dogs enter force sums. |
| `K_s1` | 10 | Sheep-sheep repulsion gain. Higher -> sheep keep more distance. |
| `K_s2` | 0.5 | Alignment gain. Higher -> velocity matching. |
| `K_s3` | 2.0 | Cohesion gain. Higher -> stronger pull into the local group. |
| `K_s4` | 5000 | Sheep-dog repulsion. Higher -> stronger flight from dogs. |
| `K_f1` | 10 | Dog attraction to target sheep. Higher -> dogs close on target. |
| `K_f2` | 200 | Dog repulsion from target. Prevents collapse onto sheep. |
| `K_f3` | 8 | Dog repulsion from goal. Keeps dogs from sitting on the goal. |
| `K_f4` | 3000 | Dog-dog repulsion. Spreads dogs into an arc; too low -> stacking. |
| `dt` | 0.05 | Integration step for `p += dt*v`. Not the same as Strombom displacement-per-tick. |
| `sheep_speed_max` / `dog_speed_max` | 5 / 10 | Velocity clamps. |

Where: paper / MATLAB gains; code `algorithms/kubo/config.py`, `forces.py`.

## Paper preset

Loads Kubo defaults and multi-dog counts. Expect force-balanced arc behind the flock and progress toward the scenario goal. Path length is not comparable tick-for-tick to Strombom without noting `dt`.
