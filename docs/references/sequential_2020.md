# Sequential Analysis of Livestock Herding Dog and Sheep Interactions (2020)

## Reference
- Sequential Analysis of Livestock Herding Dog and Sheep Interactions
- MDPI Animals, 2020
- https://www.mdpi.com/2076-2615/10/2/352

## Nature of the work
Observational ethology / sequential behavioural analysis of dog-sheep interactions. It is **not** a closed-form agent-based control algorithm with equations suitable for direct porting.

## How HerdSim uses it
Kept as a research reference for interpreting behavioural phases (approach, gather, drive, etc.). No runnable plugin is provided under `algorithms/`.

## Takeaways for modelling
- Dog and sheep actions are coupled and sequential, not independent.
- Transition structure between behaviours can inspire future mode machines or evaluation labels.
- Prefer Strombom / Kubo for executable comparative simulations in this repository.
