# Kubo et al. (2022) -- Implementation Spec

## Paper Reference
- M. Kubo, M. Tashiro, H. Sato, et al.
- "Herd guidance by multiple sheepdog agents with repulsive force"
- Artificial Life and Robotics, 27, 416-427, 2022
- DOI: https://doi.org/10.1007/s10015-021-00726-7
- MATLAB reference: `matlab/Force-Based-Sheep-Herding-Algorithm/src/main.m`

## Overview
Multiple sheepdogs herd a flock using continuous repulsive/attractive force fields. Dog-dog repulsion (`K_f4`) spreads dogs into an arc behind the flock. Each dog targets the sheep farthest from the goal within its interaction radius.

## Agents

| Type | Count | State |
|------|-------|-------|
| Sheep | N (default 40) | position, velocity |
| Sheepdogs | M (default 4) | position, velocity |

## Parameters

| Symbol | Code key | Default | Meaning |
|--------|----------|---------|---------|
| R | `radius` | 60 | Interaction / vision radius |
| K_s1 | `K_s1` | 10 | Sheep-sheep repulsion gain |
| K_s2 | `K_s2` | 0.5 | Alignment gain |
| K_s3 | `K_s3` | 2.0 | Cohesion gain |
| K_s4 | `K_s4` | 5000 | Sheep-dog repulsion gain |
| K_f1 | `K_f1` | 10 | Dog attraction to target sheep |
| K_f2 | `K_f2` | 200 | Dog repulsion from target sheep |
| K_f3 | `K_f3` | 8 | Dog repulsion from goal |
| K_f4 | `K_f4` | 3000 | Dog-dog repulsion |
| dt | `dt` | 0.05 | Integration step |
| - | `sheep_speed_max` | 5 | Sheep speed clamp |
| - | `dog_speed_max` | 10 | Dog speed clamp |

## Sheep Dynamics
For sheep i, with neighbours in radius R:
1. `a_i`: mean neighbour repulsion `diff / ||diff||^2`
2. `b_i`: mean unit velocity of moving neighbours (alignment)
3. `c_i`: cohesion `-mean(diff / ||diff||)`
4. `d_i`: mean dog repulsion `diff / ||diff||^3`
5. `v = K_s1 a + K_s2 b + K_s3 c + K_s4 d`, clamp to `sheep_speed_max`
6. `p <- p + dt * v`

## Shepherd (Dog) Dynamics
For dog i (after sheep positions are updated -- MATLAB order):
1. Find sheep within radius R (using post-step sheep positions).
2. If none: weak pull toward goal (`0.1 * unit(goal - dog)`), zero other forces.
3. Else select target = sheep in range farthest from goal.
4. `A_i`: unit attraction toward target
5. `B_i`: inverse-cube repulsion from target
6. `C_i`: unit repulsion from goal
7. `D_i`: mean inverse-cube repulsion from other dogs in range
8. `v = K_f1 A + K_f2 B + K_f3 C + K_f4 D`, clamp, integrate with `dt`

## Switching / Decision Logic
No discrete Collect/Drive modes. Behaviour emerges from force balance, especially `K_f4` spacing and farthest-sheep targeting.

## Boundary Conditions
World edge reflection plus shared obstacle resolution in `SimulationRunner` (MATLAB reference has no arena walls).

## Success Condition
Uses the active scenario (default `drive_to_goal`: all/fraction of sheep inside goal).

## Implementation Notes
- Code: `algorithms/kubo/algorithm.py`, `forces.py`, `config.py`.
- Advanced vision occlusion from MATLAB is not enabled by default (`use_advanced_vision=False`); radius neighbourhood matching MATLAB `get_sheep_in_range` is used.
- MATLAB stores agents as 2xN; HerdSim uses Nx2. Force math is identical.
- Paper/MATLAB names map 1:1 to config keys `K_s*` / `K_f*`.
- Tick order matches MATLAB: sheep forces and positions first, then dog forces on the updated flock.
