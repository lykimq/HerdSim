Giai đoạn 1: hướng dẫn

Tách riêng khỏi thư mục chạy pilot / scout / claim / t1 (thử khói / trinh sát / khẳng định / kéo dài giờ) và các file REPORT.md vận hành từng bước.

Khuyến nghị REPORT_vi.html Bản tiếng Việt: mục lục bên trái, kế hoạch → lập trình → chạy → kết quả đầy đủ (thử khói / trinh sát / khẳng định / kéo dài giờ) → biểu đồ → kết luận. Gói báo cáo tiếng Anh Bản tiếng Anh độc lập kèm hình và bảng: kế hoạch, lựa chọn, lần chạy, kết quả, khẳng định, giới hạn, bước sau. Chia sẻ share_en/ Gói tiếng Anh (có hình). Cũng có: HerdSim_Phase1_EN_share.zip
