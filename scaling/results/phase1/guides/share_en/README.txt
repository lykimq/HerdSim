HerdSim Phase 1 size map: standalone English package
====================================================

How to read:
  Open index.html (or REPORT_en.html) in any web browser.
  No git repository, server, or internet connection is required.

Contents:
  index.html     Landing page.
  REPORT_en.html The full report (plan, runs, results, claims) with figures.
  assets/        Package A PNG/CSV plus schematics/ (arena, cell, grid, window, pipeline).

The Vietnamese report is separate and is not part of this package.
