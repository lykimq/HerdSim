QUESTION What Phase 2 asks

RQ1 / Package B: at the same flock size N, does a different X0 change D_min (R >= 0.90)?

  • C1a: for at least one N, D_min differs by at least one dog-grid step across layouts.
  • C1b: early-state model predicts success better than (N, D) alone.

DESIGN Four layouts

Only the sheep start pattern X0 changes. Field, goal, dogs, N grid, D grid, theta, and T0 stay aligned with Phase 1 so layout effects are not confounded with arena changes. Cost and D_min contrasts are reported in Results.

RUN How we ran it

  1. Smoke: 600 trials.
  2. Scout: 3 N x 4 layouts x 10 D x 30 = 3,600.
  3. Claim: 24 cells x 100 = 2,400; merge 5,280 rows; Package B.

RESULTS Results

D_min = 1 for all 12 (layout, N) cells; bootstrap width zero. At D = 1 every claim cell has R = 1.00. Structure therefore does not move the reliability frontier on the baseline; it moves cost.

On wide starts, B* = 2 (not 1) at N = 50, 100 and 200: path 2,337 vs 2,925; 3,003 vs 4,319; 3,694 vs 5,213. That is the only baseline layout where adding a dog reduces total path enough to matter. Source: ../claim/packages/b/frontier_by_layout.csv.
