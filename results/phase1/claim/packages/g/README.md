Package G is early-warning analysis on failure trajectories: AUROC vs an (N, D) baseline and lead time before failure (feeds C7a/C7b). AUROC = Area Under the ROC Curve (0-to-1 ranking score; 0.5 = chance, 1.0 = perfect).

### Claims

- **C7a** (held-out state AUROC beats the `(N, D)` baseline): **INCONCLUSIVE**. AUROC means are null and folds are empty, so superiority is not established.
